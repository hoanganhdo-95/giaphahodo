``` ### Hướng dẫn sử dụng: 1. **Lưu file:** Copy đoạn code trên, lưu thành file `index.html`. 2. **Mở file:** Nhấp đúp vào file `index.html` để mở trên trình duyệt (Chrome, Cốc Cốc, Edge...). 3. **Cách vẽ và kết nối:** * **Thêm con:** Nhấn vào dấu cộng **(+)** màu xanh ở góc dưới thẻ của Bố/Mẹ, chọn "Child" (Con cái). * **Thêm vợ/chồng:** Nhấn vào dấu cộng **(+)** ở góc dưới thẻ, chọn "Partner" (Vợ/Chồng). * **Di chuyển:** Bạn có thể dùng chuột kéo cả cây hoặc kéo từng nhánh để sắp xếp lại cho đẹp. * **Sửa thông tin:** Nhấn vào biểu tượng cây bút để sửa tên, chức vụ, hoặc thay ảnh đại diện. ### Tại sao chọn cách này? * **Không cần code phức tạp:** Thư viện tự động tính toán đường nối từ cha xuống con, bạn không cần vẽ tay từng đường line như draw.io. * **Giao diện đẹp:** Có sẵn các mẫu template (trong code tôi để là "olivia", bạn có thể đổi thành "base", "ana", "mila"...). * **Dữ liệu JSON:** Dữ liệu được lưu dưới dạng JSON rất dễ dàng để đưa lên Github hoặc lưu vào Database sau này.
